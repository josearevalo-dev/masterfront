# MasterFront

**Plataforma web educativa para el aprendizaje y la consulta de desarrollo Front-End.**

**Demo: [**Ver MasterFront en línea**](https://ai.studio/apps/e790aaa0-e4f0-4293-8b4e-1026853684d5)


## Descripción

MasterFront es una plataforma web diseñada para ayudar a estudiantes, principiantes y personas autodidactas a aprender y consultar conceptos relacionados con el desarrollo Front-End. Su propósito es ofrecer un espacio de aprendizaje accesible, con artículos, ejemplos y prácticas sobre tecnologías web, complementado con un asistente virtual basado en inteligencia artificial.

## Características principales

- **Contenido educativo:** artículos de consulta sobre HTML, CSS y JavaScript.
- **Ejemplos y prácticas:** recursos para comprender los conceptos y observar su aplicación.
- **Asistente virtual:** chatbot que orienta a los usuarios con dudas de programación, explicación de conceptos, solución de errores y buenas prácticas.
- **Aprendizaje autónomo:** contenido organizado para facilitar la consulta y el aprendizaje al ritmo de cada usuario.

## Herramientas utilizadas

- **Google Stitch:** diseño de la interfaz de usuario.
- **Google AI Studio:** desarrollo de la plataforma web.
- **Botpress:** creación y configuración del asistente virtual.
- **HTML, CSS y JavaScript:** tecnologías relacionadas con el contenido educativo de la plataforma.

## Fuentes de consulta

Para orientar las respuestas del asistente virtual, se incorporaron fuentes de documentación técnica como:

- [MDN Web Docs](https://developer.mozilla.org/es/)
- [JavaScript.info](https://es.javascript.info/)
- [web.dev](https://web.dev/)

## Objetivo del proyecto

Facilitar el aprendizaje y la consulta de conceptos de desarrollo Front-End mediante una plataforma que reúna contenido educativo, recursos prácticos y asistencia virtual, con el propósito de apoyar a quienes están comenzando su camino en la programación web.

## Sobre el proyecto

MasterFront es un proyecto académico desarrollado como una iniciativa para explorar la creación de plataformas web y la integración de herramientas de inteligencia artificial en experiencias educativas.

Su desarrollo permitió trabajar con herramientas de diseño y creación de aplicaciones web, así como configurar e integrar un asistente virtual orientado a las necesidades de los usuarios.
